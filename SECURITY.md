# Security policy

Userscripts can read and modify content on matching websites and must be reviewed carefully.

- Do **not** include API tokens, passwords, credentials, customer data, private company information or internal URLs.
- Do not collect browsing data or send it to third parties without an explicit, visible reason and user consent.
- Limit `@match`, `@grant` and network permissions to what's necessary.
- Avoid dynamically loading executable code from third-party servers.
- Report potential vulnerabilities through GitHub's **private vulnerability reporting**, if enabled for this repository. If unavailable, contact a maintainer privately before disclosing details publicly. Do not post exploit details or private information in a public issue.

This repository is maintained on a best-effort basis. No guaranteed response time or formal security-support commitment is offered.
